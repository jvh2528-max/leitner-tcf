# Leitner TCF v1

نسخه اولیه PWA جعبه لایتنر برای مرور لغت و جمله‌های TCF.

## حفظ اطلاعات
- داده‌های کارت‌ها داخل IndexedDB ذخیره می‌شوند، نه داخل فایل‌های برنامه.
- آپدیت HTML/CSS/JS یا Service Worker دیتای IndexedDB را پاک نمی‌کند.
- Backup خروجی JSON می‌دهد.
- Restore فایل JSON را بدون حذف کارت‌های فعلی وارد می‌کند.
- DB_VERSION و schemaVersion برای مهاجرت امن نسخه‌های آینده در نظر گرفته شده‌اند.
